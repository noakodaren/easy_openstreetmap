This project allows easy installation and usage of the programs necessary to make high quality openstreetmap paper maps including elevation curves and other nice features.
By following the instructions below, it is almost guaranteed that everything will work as intended, thanks to [nix](https://nixos.org/) (If it doesn't please tell me).
This will be especially easy if all you want is a ski map as I have already written the code for this, but you can use this as a starting point for other custom maps.

If you want some example maps generated with this project, see <https://github.com/noakodaren/openstreetmap-maps>.

# Instructions:
- You have to run this on linux (maybe it works on macOS too, but I haven't tested it).
  If you don't use linux normally, start by creating a virtual machine with linux.
  Everything below assumes you are using linux with some standard programs installed, like bash and coreutils (you probably already have these installed).
- Download some style.
  As an example, [my own style](https://github.com/noakodaren/openstreetmap-carto) for ski maps can be downloaded with `git clone https://github.com/noakodaren/openstreetmap-carto`.
- download this project: `git clone TODO && cd TODO`
- Install nix: <https://nixos.org/download/>.
- Create a map project by doing the following:
  - Run `mkdir testproject && cd testproject && ../create_project.bash` (or something similar if you know what you are doing).
- For the rest of the instructions, see `README.md` in the new directory, or see [this file](instructions.md)

# Motivation
The reason I made this project is because installing all tools necessary to make openstreetmap maps with the normal toolchain is really annoying.
Also, most guides assume you are using a specific linux distribution, like ubuntu.
It is possible to get everything to work using the tutorials, but it takes a lot of time.
By making this project, next time I or someone else wants to setup the toolchain, it will be easy.
Also, this project makes it really easy to modify steps of the installation, as not everything has to be rerun on changes.

# Creating custom maps
If anyone actually uses this project (please tell me), I may write a short tutorial or similar, but for now I will only point to some resources.
You can start by looking at [what I changed for my own style](https://github.com/noakodaren/openstreetmap-carto/commit/08134da0d6c6f88a11cefce3fae183de8e40b6d5).
To understand the code, I recommend learning a little bit about [postgres](https://www.postgresql.org/docs/current/tutorial.html).
Some other useful resources are [the cartocss documentation](https://cartocss.readthedocs.io/en/latest/) and [this mapnik guide](https://www.get-map.org/mapnik-lost-manual/book/book.html) I found.
If you want to change for example how elevation curves are handled, look in `config/generate_contours.bash` and similar files.
